## 어떤 게임인가요?

- 공격은 **전부 자동**입니다. 여러분은 **이동만** 신경 쓰면 됩니다.
- 적을 잡으면 경험치가 떨어지고, 레벨업하면 **3장의 카드 중 하나**를 골라 새 스킬을 얻거나 강화합니다.
- 시간이 지날수록 더 강한 적이 더 많이 몰려옵니다. **최대한 오래 살아남는 것**이 목표입니다.

여기까지는 흔한 생존 게임이지만, 이 게임의 진짜 핵심은 **바닥이 빙판**이라는 점입니다.

- 펭귄은 **관성으로 미끄러집니다.** 달리다 방향을 틀면 원래 가던 쪽으로 쭉 밀려나갑니다.
- 맵 곳곳에 **얼음 구멍**이 뚫려 있고, 빠지면 **즉사**합니다. 미끄러지는 몸으로 구멍 사이를 빠져나가는 것이 이 게임의 재미입니다.

## 조작

| 키 | 동작 |
|---|---|
| `WASD` / 방향키 | 이동 |
| 마우스 클릭 또는 `1` `2` `3` | 레벨업 카드 선택 |
| `ESC` | 일시정지 / 재개 |
| `R` | 재시작 (게임오버 화면에서) |

## 게임 요소

- **스킬 13종** — 고드름, 서리 고리, 눈보라, 냉기 사슬, 우박, 눈사태, 오로라 광선, 빙결 궤적(미끄러진 길이 무기가 됩니다!) 등. 레벨업할수록 개수와 크기가 눈에 띄게 커집니다.
- **적** — 눈의 정령, 하프 물범, 얼음 골렘. 그리고 40초마다 거대한 **북극곰 보스**가 나타나며, 잡으면 경험치가 쏟아집니다.
- **자석 제단** — 맵에 놓인 제단 위에서 2초를 버티면 **맵 전체의 경험치**가 자석처럼 끌려옵니다.
